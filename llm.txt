# Loukman & Frères Immobilier

## Aperçu
Site vitrine + admin pour une agence immobilière basée à Bonoua, Côte d'Ivoire. Vente de terrains, lotissement, construction, gestion immobilière.

## Stack
- **Framework**: Nuxt 3 (Vue 3, Composition API)
- **CSS**: Tailwind CSS via @nuxtjs/tailwindcss
- **Image**: @nuxt/image
- **Base de données**: SQLite + Prisma ORM
- **Auth**: JWT (jsonwebtoken + bcryptjs)
- **Email**: Nodemailer (SMTP)
- **Animations**: Lottie (vue3-lottie), Cobe (globe 3D)
- **Polices**: Montserrat (headings), Inter (body) via @fontsource
- **Déploiement**: Vercel (nitro preset)

## Palette
- **navy**: #0B1B3D (primary)
- **gold**: #F5A623 (accent)
- **white**: bg cards/sections
- **gray**: texte secondaire

## Polices
- **Headings**: Montserrat (400, 500, 600, 700)
- **Body**: Inter (300, 400, 500, 600)

## Base de données (SQLite)
```
Admin:    id, email (unique), password (bcrypt), nom, createdAt, updatedAt
Terrain:  id, lieu, quartier, superficie, prix, statut (Disponible/Vendu/Reservé), description?, createdAt, updatedAt
Media:    id, url, type (default: image), terrainId? (FK -> Terrain, ON DELETE CASCADE), createdAt
```

## Routes API
- `GET /api/terrains` — terrains disponibles
- `GET /api/terrains/:id` — détail terrain
- `POST /api/contact` — formulaire de contact
- `POST /api/auth/login` — login admin (return JWT)
- `GET /api/auth/me` — profil admin (auth required)
- `POST /api/auth/seed` — créer admin initial
- `GET/POST /api/admin/terrains` — CRUD admin terrains
- `GET/PUT/DELETE /api/admin/terrains/:id` — CRUD admin terrain
- `POST /api/admin/medias` — ajouter média
- `DELETE /api/admin/medias/:id` — supprimer média

## Composants clés
- **ServicesGrid.vue**: Stacked cards 3D avec auto-rotation (4s), pagination, section "Notre Marque" avec logos cliquables (ouvre un modal détail)
- **TerrainsGallery.vue**: Grille responsive avec IntersectionObserver, zoom modal au clic
- **HeroSection.vue**: Titre fluide, sous-titre, CTA gold, globe 3D (Cobe)
- **SiteHeader.vue**: Nav fixe avec menu mobile hamburger, logo
- **SiteFooter.vue**: Logo, navigation, contact, copyright

## Configuration
- Site URL: https://loukman-immobilier.com (configurable via NUXT_PUBLIC_SITE_URL)
- SEO: meta tags FR, og:image, sitemap auto
- Image domains: images.unsplash.com, placehold.co
- Email: SMTP via runtimeConfig (emailHost, emailUser, emailPass, emailTo)
- JWT: secret via JWT_SECRET (default: super-secret-key-change-in-production)
- Admin seed: ADMIN_EMAIL / ADMIN_PASSWORD / ADMIN_SEED_SECRET
